Circula · Social App · Filter by Friends

Seeing which friends are going to events

Problem / Needs

///

University events are central to what Circula offers, and students often go to them with a group of friends or people they know.

I designed this filter so users can check whether their connected friends on Circula are going to the same event. It goes beyond a basic feature: the aim was to understand what motivates university students to attend events, and to encourage them to go.

User needs

Check whether connected friends on Circula are going to the same event.

Understand what motivates students to attend uni events.

Feel encouraged to go to events their friends are attending.

Process

///

User assumptions

Users want to see which friends are going to a particular event.

Users want to easily see both the event and the friends attending it on the map.

Research

Several design precedents were relevant to showing which friends are going to an event. Figma shows who else is in a shared project and whether they're online. Instagram's quick-send feature shows the friends you contact most often, so you can share a post with ease. And LINE group chats give users a quick glance at who's in the group. In each case, laying out users' profile photos signals their presence in a particular context. In Circula's friends filter, it signals participation.

Solution / Key Design Concept

///

Circula is a map-based platform, so showing the friends filter directly on the map keeps cognitive load low.

Friends are shown for every kind of event across the map. Photos of the friends attending appear on top of each event, and users can tap into an event to see everyone who's going.

Image: final map with the friends filter on
Image: tick box to turn the filter on and off

A simple tick box on the map turns the friends filter on and off.

Image: friends' photos on top of an event

Friends' photos sit on top of each event, so you can see who's going without opening it.

Image: friends shown across different event types

The filter works for every kind of event on the map, not just one category.

Image: list of all friends attending an event

Tapping an event opens the full list of friends attending.
