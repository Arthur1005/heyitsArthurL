Profile Edit

///

A redesign of Circula's Profile Editing screen, where students update their name, institution, degree, pronouns and contact details. I rebuilt it to match the design system, made editable fields easier to discover, and made sure users know whether their changes are saved before they leave the page.

Key UX decisions

Indicate that the profile picture can be changed through a dashed outline.

Provide dropdown options for users.

Separate Degrees and Area.

Add notifications when a change is not saved.

Follow / Unfollow

///

A redesign of how students follow, unfollow and send friend requests to each other on Circula. The goal was to show the status of each connection clearly, give users an easy way to cancel or undo an action, and label every button so it's obvious what it does.

Key UX decisions

Clearly inform instructions and help.

Distinguish different statuses through an icon system.

Distinguish the style of action and cancel buttons.

Clearly label and phrase the CTA buttons.

Filter by Friends

///

A tick-box filter on Circula's event map that shows which of your connected friends are going to each event. Friends' photos appear on top of every event they're attending, and tapping an event shows everyone from your network who's going.

Key UX decisions

A simple tick box on the map turns the friends filter on and off.

Friends' photos sit on top of each event, so you can see who's going without opening it.

Tapping an event opens the full list of friends attending.
